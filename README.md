# windows-19

A small Windows 10 deployment template for quick setup or VM provisioning.

## Files

- [Win10VLqL.yml](Win10VLqL.yml) — example Windows 10 configuration

## Quick start

1. Review the values in [Win10VLqL.yml](Win10VLqL.yml).
2. Replace the placeholder ISO path, product key, and admin password.
3. Use the YAML as a base for a VM, automation tool, or provisioning workflow.

## Notes

This repo intentionally keeps the configuration minimal and editable so it can be adapted for local lab use, testing, or a quick Windows 10 setup.
